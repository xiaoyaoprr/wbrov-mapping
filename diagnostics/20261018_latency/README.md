# 延迟优化与完整录像验收

本目录是隔离候选的闭合录像回放证据。未切换生产 8 号。没有重新采集相机、打开灯光或发送推进指令。

完整现场录像 `live_latency_v18`：397.832 秒、10,746 帧输入，处理耗时 653.943 秒；此前完整回放耗时 1,195.117 秒。耗时减少约 45%，仍慢于采集速度，不能当作低延迟上线验收。

- `live_latency_v18/latency_audit.json`：闭库后的独立审计。一次恢复后主图从 77 节点增至 155 节点，继续处理 158.159 秒；216 个失锁帧没有主图写入许可；全部输入时间戳对应。
- `live_latency_v18/mapping/main_cloud.ply`：62,091 点，只含已注册主图；与从该次闭合数据库完整重算的结果逐字节一致。
- `live_latency_v18/mapping/tags.json`：Tag 8 和 13 均有三组独立参考；155 个可信历史轨迹节点、153 条同历元边。
- `ui_full_v18/`：设备实际 RViz 截图，包含建图、暂停、恢复核验和已保存。保存截图已目视核对点云、Tag、轨迹与中文状态；橙色箭头是最后可信记录位姿，不是当前导航位姿。
- `motion_latency_v*/`：同一 65 秒区间的审计和保存回执。v13、v19 的最终恢复验收失败原样保留；`save.complete=true` 不代表恢复验收通过。
- `lookahead_negative_v*/`：改动输入身份、错误哈希、提前关闭的拒绝测试，下一段均没有写入或 ACK。
- `native_release_v1/`：相同源码 O3 编译和回归记录。最初缺少 AMENT 环境的 Wrapper 失败及补齐环境后通过的记录都保留。
- `identity.json`：worker、候选源码、生产入口哈希和最终进程/UDP 3333 检查。

v19 的额外调度抑制已撤回。v20 的三帧特征预处理通过短录像恢复与数据校验，但未改善总耗时，默认关闭。v21 精确匹配参数也未获得总耗时收益，未纳入默认配置。具体边界见 [候选说明](../../docs/ROUND7_CONTINUOUS_MAPPING_20261018.md)。
