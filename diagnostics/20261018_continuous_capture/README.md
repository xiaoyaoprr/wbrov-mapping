# 持续采集候选版的现场序列

操作员完成自然移动、短暂遮挡、恢复视野和再次移动。相机持续录制，后台按原始时间戳处理；本轮未发送推进或解锁指令。设备时钟为 10 月 11 日，目录按工作站的 10 月 18 日归档。

`acceptance.json` 汇总现场序列的处理与保存检查。`save.json` 仅证明输出正常关闭及文件哈希；它的 `recovery_acceptance_passed=false` 不会被通用保存程序自动改为成功。独立审计记录一次主图恢复及其后的持续新增节点，同时保留 `production_entry8_acceptance_passed=false`。

- `capture_status.json`、`spool_status.json`：连续 SVO 与 RGB-D 磁盘队列的关闭计数。
- `recording_verification.json`：SVO 索引、首尾解码及配置哈希；不是所有曝光无损或逐帧全分辨率解码证明。
- `frames.csv`：10,746 帧的跟踪、门控和主图计数。`main_write` 表示该帧的写入许可，并不表示每帧都创建节点。
- `processing_status.json`：最终积压为 0、163 个主图节点、62,682 个点。
- `tags.json`：Tag 8、13 的主图绑定与参考准备度。此首轮现场版本尚未导出轨迹字段；后续 UI 回放单独记录。
- `main_cloud.ply`：本次已验证主图的实际保存结果，仅用于复审。这是局部室内相机测试点云，不是完整水下任务地图。

数据库和原始图像/SVO 保留在设备测试目录，未放入仓库。点云按用户授权纳入诊断材料。源时间、点云位置和历史输出均不能用作当前机器人的导航位姿。

首轮总流程约 1,152 秒，而采集只持续 397.832 秒。恢复和保存通过不代表后台吞吐满足上线要求；生产 8 号尚未切换。实现与后续检查见 [候选说明](../../docs/ROUND7_CONTINUOUS_MAPPING_20261018.md)。
