# 新增状态、Tag 与轨迹显示的核验

使用前一目录现场采集的 10,746 帧进行完整回放，并实际打开 Jetson 上的 RViz。截图是设备实际屏幕，未后期改图。回放期间没有相机采集、灯光控制或推进指令。

- `rviz_saved.png`：最终显示版本，Tag8/Tag13 编号抬离密集箱壁点云，以黄色引线连接实际位置；中文状态显示已保存、积压为 0；青色线为可信轨迹，橙色箭头为最后可信记录位姿。
- `rviz_paused_before_label_fix.png`、`rviz_recovering_before_label_fix.png`：真实状态切换证据。它们属于 Tag 文字间距修正前的显示版本，也保留了离线回放中多余的相机面板。最终离线检查配置已移除这个空面板。
- `full_recording_replay_audit.json`：帧数、一次恢复、恢复后新增节点、已关闭数据库检查、输出哈希及轨迹边核验。
- `python_tests.json`：Jetson 上 7 项磁盘队列、2 项录制像素与 2 项显示策略测试结果。
- `screenshots.json`：截图哈希及人工像素核对范围。
- `receipts/`：后续线程、阶段耗时和点云组装对照，以及最新缺输入状态修正后的回放。旧版审计中的 false 结果原样保留；缺 IMU 帧错误沿用上一帧写入标识的问题及修正解释见候选说明。

这里显示的是录像时刻的地图和轨迹，不是当前导航位姿。轨迹不跨失锁历元推测连线。Tag 引线的下端才是测量位置，抬高的文字只是标注。

回放恢复与保存正常不代表延迟满足上线要求。本次约 398 秒输入耗时约 1,195 秒；性能对照和候选实现见 [说明](../../docs/ROUND7_CONTINUOUS_MAPPING_20261018.md)。生产 8 号和 GitHub 发布状态仍需在最终验收后更新。
