# v30 离线优化记录（实机待验）

本次只读取已关闭的录制，未开启相机、灯光或遥控。生产 8 号没有切换。

变化限于 RGB-D 无损封存/读取和点云导出的采样缓存，Core v5、位姿质量门槛、主图恢复条件、体素大小、像素采样间隔不变。所有已接受的输入帧按原时间处理。

## 已确认的结果

- 完整录像 10,746 帧、375 段全部经过逐字节编码/解码验证。RGB、float32 深度（包括 NaN 位模式）、IMU、内参和纳秒时间戳均不改动。约 14.19 GB 的段数据降到 9.08 GB（少 36.0%），未重压缩原始 SVO。
- 压缩格式短录像：1,581 帧，120.345 秒；一次恢复后主图由 91 增至 97 节点。数据库关闭及点云逐字节重组对照通过。相比 v26 的 104.244 秒，这个短样本没有加速，不能把减少写盘字节等同于提高计算吞吐。
- 完整旧格式录像：10,746 帧、397.832 秒源时间，处理 510.188 秒；一次恢复后主图由 76 增至 157 节点，继续处理 159.276 秒。最终 62,558 点，不可信帧主图写入数为零，数据库和点云重组检查通过。v26 为 519.658 秒，只是小幅改善，仍慢于采集速度。
- 新入口、队列、显示和解码共 17 项 Python 测试通过；相机 12 项原生测试、处理程序的缓存与预读原生测试通过。入口只完成预检，不能当成实机联合运行验收。

- 大地图中断录像：10,059 帧全部处理，耗时 1,033.200 秒，470 个主图节点、440,297 点；一次恢复后继续增加 5 个节点，结尾再次处于恢复观察中。原录像非正常关闭，所以队列按预期退出 2，保存为 `complete=false` 的中断结果。数据库、保存文件哈希和点云重组通过。
- 大地图相机点采样构建 470 次，解压累计 3.468 秒；原第二次现场记录为 83,615 次、569.160 秒。点云总导出仍用 626.343 秒，是剩余主要瓶颈。原现场整轮为 2,079.110 秒，包含并发采集与显示，本轮是独立离线回放，不能把二者直接当成同负载的两倍加速测量。
- 按原速度写盘：1,581 帧、64.947 秒源时间，65.063 秒全部正常封存；所有记录逐字节一致，队列满等待 0 次，提交 P99 为 0.965 ms、最长 4.490 ms。没有触发超过 500 ms 的封存慢日志；`io_max_ms` 中的 0 表示没有该阈值日志，**不是 fsync 耗时为零**。此测试没有并发 SVO、相机推理或建图，不能替代实机压力验证。
- 三组回放共 22,386 帧，逐帧源时间戳与输入完全一致。完整录像有 215 个失锁帧，均未取得主图写入许可。审计见 `audit.json`；`result.json` 的 `steps.exit` 是点云重组校验进程退出码，队列退出码在审计中另列。

两个版本的配准/建图结果有节点数差异，点云对照是各自按自身数据库重新组装的逐字节对照，不宣称两次建图完全相同。无损编码与缓存修改不改变点云分辨率或写入门槛，但真实几何精度仍需另行检验。

## 明日验收边界

先检查空间、冻结包身份和入口占用，再实际启动候选。确认 RGB、点云、状态、Tag、轨迹和三轴显示；自动积累足够参考后，由操作员做一次短暂遮挡及恢复后的移动，最后正常停止，检查录像封存、积压排空、数据库、点云及灯光退出。真实相机、SVO 和后台计算同时运行时的写盘稳定性尚未证明。

未通过这组实机验收之前，不把隔离候选切换到 8 号，不以新版本完成的口径更新 GitHub。

压缩只能减少后续采集的写盘量，不能补回第三次实机写盘等待期间没有抓取到的图像；这些旧缺口继续按原质量条件处理。尚未验证水下尺寸精度，操作者报告的地图变形也不以吞吐优化作为已修复证据。
