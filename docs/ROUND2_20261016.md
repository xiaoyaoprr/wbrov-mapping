# 第二轮审查修正

本轮针对审查报告核实后的问题修改。内点数量、有效深度数量、空间分布、最终配准残差、观察期及事务提交阈值保持不变。

## 候选一致性的噪声模型

`Rtabmap/CrossMapLoopMinLinearSigma`（米）和 `Rtabmap/CrossMapLoopMinAngularSigma`（度）仅影响受保护模式中的跨图候选收集。默认使用最终RGB-D桥接已有的2厘米/3度尺度；参数允许从0调到该上限，0保留原始协方差归一化行为。这是候选噪声模型的保守下限，未经水下标定，不代表传感器精度或统计置信区间。

每个候选保留原始协方差；比较时对两侧方差分别取下限，再求和归一化。候选由局部配准和两侧里程计位姿组成，局部配准的数值epsilon不应被解释为整项坐标对齐的精度。加入有限、对称、正定检查，避免下限掩盖无效协方差。已有绝对一致性阈值保留。

这条路径始终返回“不授权普通跨图加边”。三个候选之后仍须重新读取六份原始RGB-D、双向复验、影子优化、留出检验、观察期及最终提交。非保护模式的原生回环不使用新下限；最终桥接信息矩阵的权重没有改变。

新增日志同时记录原始方差、有效下限、归一化误差和绝对阈值。支持度日志包含内点总数、去重数量、两侧网格覆盖、有效深度数量及最终复验门槛。最终复验分别报告正反方向失败原因，便于区分候选筛选和最终提交阻塞。

## 早期重力证书与重试

`early_component_gate.inc`、`early_shadow_guard.inc` 现在由实际编译的 `Rtabmap.cpp` 包含，原内联副本移除。早期证书保留现行的必检行为；不恢复旧实验环境开关。两份包含文件及主源文件继续受运行包源码哈希约束。

Python的可选 `WBROV_PRIVATE_EARLY_TAG_RETRY` 只控制重试调度，不再要求已失效的 `WBROV_PRIVATE_EARLY_GRAVITY_CERTIFICATE`。新旧两种Core重力稳定性拒绝文案均可进入原有有界重试流程；默认重试策略和Core几何检查保持不变。

## 回放指标

`replay_timing.schedule_budget_met` 明确表示回放发布调度是否满足既定P95小于30毫秒、最大迟到小于150毫秒的预算。算法证据仍单独记录；迟到可能实际影响恢复，不能据此宣称与时间无关。旧 `source_realtime_valid` 字段保留为同一布尔值的弃用兼容别名，预算未放宽。

所有录制回放均标记 `live_sensor_realtime_validated=false`。源时间戳和运行时新鲜度门不变；真实相机的实时性须从实机健康记录获得。

## 审查结论的边界

旧回放不仅有协方差拒绝，也有当前侧仅5个有效深度内点及多次覆盖不足。恰好25个独立内点可以通过现有数量门；不存在必须提高到35才能解决的“阈值碰撞”。最终复验要求的3D点比候选门更严格，因此本轮不放宽深度或内点条件。

原生合成数据曾验证后半段事务，但不能替代录制数据自然检索、移动回航或水下精度验收。`unannounced_jump_quarantine_enabled` 在桌面8号仍为默认关闭；历史录制回放显式开启，两者需分别解释，不能声称该门在生产入口生效。
