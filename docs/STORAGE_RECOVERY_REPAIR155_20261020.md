## 软件修改

1. **补齐后台处理的异常局部运动隔离。** 回放适配器原先遗漏了实时路径已有的隔离步骤。只有独立原始RGB-D检查确实发现局部运动矛盾时才隔离旧段；未知空档不补点。
2. **修正恢复检索的关键帧身份。** 生成过的ID不等于最终保留的关键帧。改为读取实际保留的工作节点和对应认证回执，补查因恢复票据尚未稳定而漏掉的首个有效参考，避免反复检索同一帧。
3. **按最终变换重新验证原始内点。** RANSAC内点标签早于BA修正。只在原始唯一对应集合中按最终25毫米以内残差重新分类，保留原始全集RMS≤18毫米、最终RMS≤18毫米、至少25内点及更高配置门槛、分布、三维跨度、退化和协方差检查；不增加匹配或通过删点重拟合位姿。
4. **坏参考允许有界替换。** 某个旧节点粗匹配通过、严格几何不通过时，不再永远占据候选位置。对同一认证当前帧，在有限范围内尝试其他独立旧参考；候选收集不提交图。
5. **在恢复验证中使用RGB-D与实测重力。** 先独立完成原始双向六自由度配准，再在实测重力约束下从同一原始对应拟合偏航和平移。新解再次通过原几何、双向、原解一致、里程计和邻边门槛。局部轨迹积分使用该联合解；每个节点必须有有效实测重力，优化后位姿不能冒充测量。

三组独立桥接、整段局部验证、固定旧图的影子优化、留出验证、观察期、25毫米/2度一致性、20毫米z/2度倾斜，以及原有重力增量检查保留。配置参数、所有输入帧、点云密度、Tag路径和无Tag视觉路径保持；不把未锚定子图当作主图显示。
