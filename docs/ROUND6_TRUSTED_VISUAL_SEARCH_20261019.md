# 无 Tag 恢复中的旧主图候选检索

现场 v5 的核心日志补齐后发现：最后一条跨图候选为 current=392、old=157，因当前视角与既有候选不够独立而拒绝。此后仍有 33 条同 epoch 的回环拒绝记录，但没有新的跨图候选。处理台账 395 帧、约 30.55 秒源时间持续报告最新桥 391 过期。这些是持续状态的重复记录，不是 395 次独立故障。

旧流程只在普通回环首选结果落在可信主图时调用跨图候选收集。新子图内已有相似画面后，普通回环首选可能一直落在本地；这不能证明主图不可匹配，却使主图恢复不再获得新候选。旧三桥曾被几何一致性拒绝，这类合理拒绝仍需保留，不能通过延长有效期或放松阈值绕过。

候选 9 增加独立的可信主图检索：只访问 Core 持有、与当前来源上下文一致的主图节点，以共享词典相似度排序，在前 12 个中优先选择尚未占用的旧端点，每个已保留当前关键帧最多做 6 次原始 RGB-D 候选配准。普通回环已收集当前节点时直接复用，不重复加候选。同一当前节点仍最多一个候选，三个旧端点及当前视角独立性仍由原逻辑约束。

检索结果只进入候选池，不添加图边、不改变地图校正、不注册 epoch。完整双向原始配准、三桥一致性、连续局部段复验、观察期和最终提交票据仍决定能否恢复主图写入。增加 `visual_candidate_search` 状态字段，并在三桥不一致理由中记录实际平移和旋转差值。所有帧、点云密度和几何阈值不变。

新增原生回归关闭普通回环候选产生：先保留两个真实原始配准候选，验证不能准备合并，再由独立可信主图检索补充当前候选，检查原准备路径通过且图与注册状态均未变化。错误源上下文及重复当前观测不得改变候选池。首次编译遗漏测试辅助头，随后工作进程编译又遗漏旧包中的辅助头；两次打包失败保留，补齐后继续对应步骤，不重跑已通过的 Core 测试。最终录像对照结果另行记录。

三次均校验全部源时间、每段输入哈希、保存文件哈希及已关闭数据库 `quick_check`；没有向主图写入失锁或缺失输入帧。最后仍为 `RECOVERING`，**没有一次可算作无 Tag 恢复成功**。候选9比基线获得更多旧图候选，但后续多次被重力一致性拒绝，最后一条检查为6个节点、6个实测重力约束、8.399秒源跨度；对齐前平均重力残差0.361°，对齐后最大均值1.876°，最大残差增加1.878°，超过原0.5°限制。候选10最后是候选源时间过期；此前也出现观察期原始图像配准不足。不能把这几个拒绝原因合并称为“Tag 不可见”。

候选9的额外计算来自一个调用条件遗漏：Core成功处理新输入时不一定创建新关键帧，而检索仍对上一个已存关键帧重复执行。候选10仅在当前输入的认证回执确实成为新保存节点时执行新增检索；处理全部输入帧、原几何准备、观察期和提交条件不变。实测执行14次新增检索、跳过69次重复检索，并在状态中输出这两个计数。候选10只重新编译worker，Core9及原生测试结果不变。上述是各版本单次实测，不是多次统计性能结论；随机配准及图优化结果存在差异，不将节点数差异单独归因于检索改动。

首次回放检查脚本误把基线动态库目录指定为旧构建目录，实际加载的是候选8包中哈希相同的Core6；检查在任何帧处理前拒绝。修正路径并增加固定库哈希后才执行上述对照，原失败记录保留。

另选一段已完整保存的现场记录，关闭Tag，单次处理6,412帧、306.052秒源数据，耗时165.739秒。全部输入和保存校验通过，最后30个主图节点、0次恢复、`PAUSED`。按切链计数的实际增量统计53次：33次里程计丢失、18次未经测量确认的采样空档、2次几何质量不足；不是把同一个状态重复出现的日志行计为故障。该旧记录本身有31个超过300ms的源间隔，最长14.032秒；本轮处理完整不等于历史采集连续。正常跟踪段仍写入主图，无法确认的区段继续隔离，没有非法主图写入。结果在 `diagnostics/20261019_round6_recovery10/long6412`，同样不算恢复通过。

最初指定的10,746帧压缩缓存已不在设备上，检查在处理任何帧前因缺少输入停止；保留这份失败，再检查仍存在的6,412帧完整源数据后选用它。没有重新备份视频，也没有重复失败的短录像直到通过。

诊断证据分别在 `diagnostics/20261019_round6_recovery9` 与 `diagnostics/20261019_round6_recovery10`。只读检查关闭数据库时，进一步发现部分已优化主图节点也有较大的重力残差；这只说明视觉地图与IMU之间还有一致性问题，尚不能区分深度/标定、姿态同步或配准误差，不是放宽重力门槛的依据。原始里程计位姿和优化后的地图位姿分开统计，不能混作一项。

当前仍是独立候选；本轮没有开启相机、灯光或运动控制，也未替换生产 8 号。下一步需定位剩余姿态/几何不一致，之后才能进行移动恢复实机验收。
