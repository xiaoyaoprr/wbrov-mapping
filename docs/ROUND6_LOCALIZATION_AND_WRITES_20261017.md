# 当前定位与地图写入分离（候选版）

状态：正在验证。未切换桌面 8 号入口，未发布为实机验收版本。

## 行为

- `localization_status` 描述当前定位，`main_map_write_allowed` 独立描述地图写入。找到主图位置不注册子图、不修改主图变换，也不授权自动控制。
- 在失锁后的当前局部坐标系中，检索可信历史帧，用当前 RGB-D 对两个独立旧参考做双向原始数据配准。检索不受失锁前位置的 1 米邻域限制；仍检查几何质量、歧义、配准一致性和实测重力方向。
- 连续三次位置测量一致、源时间跨度至少 500 ms 后可显示当前位置。需要同一连续跟踪段中的新鲜实测里程计；再次切链、历元改变或测量过期会撤回定位显示。主图写入仍经过原有独立恢复观察与提交。
- 定位核验使用当前接收并验证过来源的 RGB-D，即使静止观测没有保留为新节点，也可继续完成定位观察。位置显示由经过身份准入的高频里程计传播，不使用低频建图回调中的旧位置冒充实时位置；里程计换链、过期或无法取得一致快照时撤回有效显示。
- 质量合格的自然移动达到 3.5 cm 或 3.5°，且距上一参考至少 200 ms 时，可以提前保留关键帧。静止重复图像不充当不同视角。历史 Tag 参考优先保留不同视角，不再仅按图像面积选前 24 帧。
- RViz 分开显示定位状态、写图状态和 Tag 参考准备情况。历史快照仅供参考，不要求操作员复现最后一帧。

## 接口

- `/wbrov/mapping_continuity/status`：新增定位状态、测量数量、源时间和结构化匹配拒绝计数。
- `/wbrov/localization/pose`：通过独立定位核验、由新鲜实测里程计传播的当前位姿，使用主图坐标。不会改写 TF 或导航授权。
- `/wbrov/localization/markers`：短寿命定位箭头，数据不再更新即消失。
- `/wbrov/mapping/reference_readiness`：只读参考准备度；三个有效历史参考齐备不代表恢复已经通过。

## 验证边界

原生合成场景覆盖：错误的 10 米位置预测、两个旧 RGB-D 锚点定位成功、图状态不变、缺少或冲突重力拒绝，以及静止帧未保留为节点时仍能核验、像素身份不符时拒绝。状态机覆盖测量过期、新切链、历元切换和不一致修正。Wrapper 测试覆盖高频里程计的位置时效、换链和身份锁繁忙时不显示有效定位。Python 与 ROS 显示验证覆盖参考保留、源消失、定位与写图分别显示以及旧状态清理。

这些证据不等于水下动态验收。候选版仍须实际打开相机和 RViz，验证点云、遮挡后的定位与主图恢复、恢复后的持续建图，以及正常退出保存。只有完成这些步骤，才更新 8 号入口和 GitHub 交付状态。
